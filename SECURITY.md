# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or critical crash exploit in **Pawno Studio Mobile** or any of its embedded native compilers, please do not file a public issue.

Instead, please report the vulnerability privately by sending an email to:
📧 `lutpilarsi614@gmail.com`

Please include:
1. Description of the vulnerability or exploit.
2. Steps to reproduce the issue (including sample `.pwn` script if applicable).
3. Potential impact on the device or user data.

You should receive a response within 48 hours. Valid vulnerabilities will be patched promptly and released in the next update.
